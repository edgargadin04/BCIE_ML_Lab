✅ Recomendados para Segmentación Operativa
KMeans (K=4) — La opción más interpretable y estable (ARI=0.998). Produce 4 segmentos claros y balanceados. ⭐ Primera elección para negocio.
DBSCAN (K=3) — Detecta 3 tiers operativos claros (Regular/High Value/Low Value) + ruido controlado (13.9%). Ideal para clasificación por densidad.
Mixed (K=3) — Mejor Silhouette (0.830) y DBI (0.230), pero estabilidad desconocida. Usar solo para validar otros modelos.
⚠️ Uso Especializado
HDBSCAN (K=14) — Demasiados micro-clusters con 26.7% de ruido. Difícil de operativizar. → Solo para detección de anomalías.
GMM (K=3) — Membresía suave útil para casos ambiguos, pero Calinski más bajo (376). → Para clasificación probabilística.
KMedoids (K=4) — Resultados casi idénticos a KMeans pero con estabilidad inferior (0.837). → Elegir solo si hay outliers extremos.

📋 Recomendación del Laboratorio
Para Producción: StatsForecast — Ensemble robusto y conservador. Intervalos de confianza al 80%. La opción más segura para reportes financieros.
Para Exploración: TimesFM — MAPE <30% en economías estables (Costa Rica). Representa el estado del arte en IA generativa para series temporales.
Para Interpretabilidad: Prophet — Descomposición clara en tendencia + estacionalidad + feriados. Ideal cuando el negocio necesita explicar las proyecciones.
