Distribución de Entropía

Interpretación

  • BIC (Bayesian Information Criterion): Utilizado para seleccionar K. Un valor más bajo indica mejor balance entre precisión y parsimonia.
  • Entropía: Indica la incertidumbre de la asignación. Valores cercanos a 0 son asignaciones seguras.

Parámetros del Modelo GMM

  • Algoritmo: GaussianMixture (Scikit-Learn).
  • Componentes (K): Optimizado dinámicamente.
  • Covariance Type: 'full' (Cada cluster tiene su propia matriz de covarianza general).
  • Inicialización: K-Means.
  • Regularización: 1e-6 (para estabilidad numérica).
  • Features: Log1p(Monto), Cantidad de Aprobaciones.
  • Escalado: StandardScaler (Media 0, Varianza 1).

Metodología de Segmentación

El modelo utiliza un enfoque de Soft Clustering probabilístico (GMM), optimizado para capturar la estructura latente de la cartera de inversiones.

1. Procesamiento y Limpieza

  • Agregación: Datos consolidados a nivel País por Monto Aprobado y Frecuencia de Operaciones.
  • Transformación: Aplicación de Log1p (logaritmo natural) a los montos para normalizar la distribución financiera asimétrica ("long-tail").
  • Estandarización: Uso de StandardScaler (Z-Score) para centrar las variables (Media=0, Std=1) y asegurar equiparidad de escalas.

2. Modelado (GMM)

Algoritmo Gaussian Mixture Model mediante Expectation-Maximization (EM):

  • Covarianza 'Full': Permite clusters con formas elípticas y rotadas, adaptándose a la correlación real entre Monto y Frecuencia.
  • Probabilidad Posterior: Calcula P(Ck|x) para cada país, permitiendo asignaciones parciales (ej. 80% Cluster A, 20% Cluster B).

3. Validación y Selección

  • Criterio BIC: Selección automática de K componentes que minimiza el Bayesian Information Criterion, penalizando la complejidad para evitar overfitting.
  • Análisis de Entropía: Medición de la incertidumbre en la asignación (∑ -p · log(p)) para detectar países en zonas de transición.
  • Estabilidad: Inicialización mediante K-Means++ y regularización (1e-6) para garantizar convergencia robusta.

Key Insights: Estrategia & Precisión

🎯 1. SEGMENTACIÓN PROBABILÍSTICA (SOFT CLUSTERING)

A diferencia de modelos rígidos, GMM calcula la probabilidad de pertenencia de cada país a múltiples segmentos. Esto permite identificar economías "híbridas" o en transición (ej. operativamente similares al Cluster A pero con montos del Cluster B), ofreciendo una visión más matizada para diseñar estrategias de evolución de cartera.

📐 2. VALIDACIÓN ESTADÍSTICA ROBUSTA (BIC)

El modelo ha sido optimizado seleccionando el número de clusters que minimiza el Criterio de Información Bayesiano (BIC). Esto garantiza un equilibrio matemático perfecto: suficiente complejidad para capturar patrones reales en la inversión del BCIE, pero evitando el ruido aleatorio para asegurar conclusiones accionables.

📊 3. GESTIÓN DE INCERTIDUMBRE (ENTROPÍA)

El dashboard integra la Entropía como métrica de riesgo de asignación. Los puntos con alta entropía (asignación difusa) se destacan visualmente, señalando operaciones que requieren revisión manual o estratégica, transformando la incertidumbre matemática en un indicador de atención prioritaria.
